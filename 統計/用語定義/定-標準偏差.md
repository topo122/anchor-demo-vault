# 標準偏差とは

標準偏差とは何か。分散との関係がわかるように述べよ。

<!-- back -->

各値と平均の差（偏差）を2乗して平均したものが**分散**、その**正の平方根**が**標準偏差**。単位は元のデータと同じになる。

> 分散 ＝ （各値 − 平均）を2乗した値の平均
> 標準偏差 ＝ 分散の正の平方根

- 偏差をそのまま足すと必ず 0 になる（正と負が打ち消し合う）。だから2乗してから均す。
- 手元のデータそのものを記述するなら個数 n で割り、その背後の母集団を推定するなら n−1 で割る（不偏分散）。

<!-- note -->

表計算ソフトの関数名も STDEV.P（母集団）と STDEV.S（標本）で分かれている。
