# 0031a　罪刑法定主義の根拠

罪刑法定主義（法律なければ犯罪なく、法律なければ刑罰なし）は、憲法のどの条文に根拠があるか。2つ挙げ、それぞれが何を求めているか述べよ。

<!-- back -->

- **31条** … 法律の定める手続によらなければ刑罰を科されない。手続だけでなく、何が犯罪でどんな刑を科すかを**法律で定めること**、その定めが**明確であること**も求めていると解されている。
- **39条前段** … 実行の時に適法であった行為を、後から作った法律で処罰しない（**遡及処罰の禁止**）。

刑の重さが行為の後に変わったときは、軽いほうの刑による（刑法6条）。これは遡及処罰の禁止とは別に、法律が定めた扱いである。

<!-- note -->

刑罰法規があいまいで、ふつうの判断能力を持つ人がどの行為が処罰されるのか判断できないときは、31条に違反して無効となる（明確性の理論）。

出典：憲法31条・39条、刑法6条、最大判昭和50年9月10日刑集29巻8号489頁（徳島市公安条例事件）。
